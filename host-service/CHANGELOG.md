# 版本說明

主機服務每個版本的更新內容。發行時 Release 頁面會帶上對應版本這一段;發新版前先在最上面加一段 `## <版本>`。

## 0.16.0

- 新增更多推播通知種類(需要後台支援):
  - Agent 完成時,推播會帶上 Agent 的工作時間,後台用來判斷長時間工作(通知種類需要後台支援)。
  - 預約送出(Send When Done)因為 session 換了而暫停時,會推播通知你。
  - Claude 或 Codex 的方案用量超過 80%、95% 時各推播一次。
  - 主機服務會定期向後台回報在線狀態,macOS 睡眠前會先回報「睡眠中」;只有在你開了主機離線或恢復通知時才會送,內容只有配對識別與狀態。
- 主機外掛 0.3.0(SSH 主機):同樣支援工作時間與方案用量推播。
- 修正：用 `ſ`、`ß`、`ﬅ` 這類長得像英文的字元拼寫的機密檔名(例如 `.ſsh`、`.git-credentialſ`),不會再被手機讀到(#94)。

## 0.15.0

- 從手機可以在既有的 Workspace 新增聊天(新增 Tab),也可以在聊天列表關閉 Tab。關掉 Workspace 的最後一個 Tab 時，Workspace 會一併關閉。
- 新增聊天時會等 Agent 真的就緒才回報;資料夾尚未被 Claude 信任、卡在確認畫面時，手機會知道還沒就緒，不會誤送出第一則訊息。

## 0.14.1

- 修正用 HTTPS 連線時，從手機開的 Codex 聊天有時讀不到對話內容的問題。

## 0.14.0

- 安裝前先列出這次會用的設定(連接埠、HTTPS 網址、自動更新等),可以直接照建議安裝、逐項自訂或取消。
- HTTPS 埠被其他服務占用時，會自動建議一個空的埠並說明原因。
- 重新安裝會沿用上次的設定;安裝完成畫面會列出之後怎麼修改。
- 每個設定都能用參數或 `PURRDR_*` 環境變數指定，Windows 的一行安裝指令也能帶設定。
- 替你安裝的 AI agent 可以用 `--json` 取得安裝結果。

## 0.13.1

- 可以在 app 上替 Tab 改名。

## 0.13.0

- 通知會帶上 Tab 名稱(沒有命名就用 Agent 名稱),一眼看出是哪個對話需要你。
- 你在 app 上傳、寫進訊息裡的檔案，之後在對話裡也能直接打開。
- 推播外掛會跟著主機服務自動更新，不用再手動處理。

## 0.12.1

- 修正在 herdr 0.9.5 上，主機服務沒辦法直接送出「需要你」與「完成」通知的問題；「做完再送」與卡住提醒也因此恢復作用。

## 0.12.0

- 用 HTTPS 連線的電腦，也能在 app 上看到 Claude 與 Codex 的方案用量，以及每個對話用了多少 context。
- 在 app 上新增對話時，可以瀏覽電腦上的資料夾來選擇位置。
- 「需要你」與「完成」的通知改由主機服務直接送出，不必再另外安裝推播外掛。
- 修正 macOS 上重新執行安裝指令時，服務可能沒有啟動的問題。

## 0.11.0

- 可以從 app 傳送一則測試通知，確認這台電腦的推播設定正常。
- 在 app 打開聊天時只先讀最後一小段，網路慢時也能比較快看到對話。

## 0.10.1

- 修正 Windows 上用 `purrdr` 執行的指令失敗時，仍被當成成功的問題。
- 裝置管理的提示訊息改成較短的 `purrdr` 指令。

## 0.10.0

- 新增短指令 `purrdr`:重開終端機後打 `purrdr pair` 就能顯示配對 QR code,`purrdr help` 列出所有指令。原本的 `purrdr-host-service` 照樣能用。
- 自動更新到這版的電腦，在服務重新啟動後也會有 `purrdr`。

## 0.9.0

- 安裝時在 herdr 加上快捷鍵:在 herdr 裡按 `prefix+alt+p` 就會跳出配對 QR code。這個按鍵已經被你使用時不會加。

## 0.8.0

- 從 app 上傳的檔案改放在系統的暫存資料夾。
- 主機服務的紀錄檔集中放在一個資料夾，方便查問題。

## 0.7.0

- 在 app 上可以看到 Agent 目前的畫面。
- 送出訊息前會先確認畫面沒有變動，避免送錯地方。
- Agent 卡住或在等你回覆時，會推播通知。
- 可以排一則「Agent 做完再送」的訊息。
- 可以接續之前的對話，也能查看專案的 git 變更(唯讀)。
- 修正 Windows 上背景啟動的問題。

## 0.6.1

- 可以從 app 聊天、建立工作區，以及上傳圖片與檔案。
- 可以從 app 查看與撤銷已配對的裝置，並管理主機服務(查看狀態、立即更新、開關自動更新)。
- 有新版時會推播通知;Agent 正在工作時，自動更新會等它做完再進行。
- 補上 macOS 版的 Apple 公證。

## 0.6.0

- 可以從 app 安裝推播外掛，一台電腦能配對多台裝置。
- 安裝時會把主機服務加進 PATH,重開終端機後可以直接執行。

## 0.5.0

- 新增自動更新：每天檢查一次，有新版就自動更新;新版起不來會自動退回原本的版本。
- 新增 `update`、`version` 與 `auto-update on|off` 指令。

## 0.4.1

- 專案網址改為 `raychiutw/purrdr.host`。

## 0.4.0

- 第一個可以用一行指令安裝的版本(macOS、Linux、Windows)。
- 支援配對裝置、從 app 讀取電腦上的檔案，並可在安裝時指定 HTTPS 連接埠。

## 0.2.0

- 第一個公開版本：讓 iPhone／iPad 上的 Purrdr app 透過 HTTPS 連到電腦上的 herdr。
