# 版本說明

主機服務每個版本的更新內容。發行時 Release 頁面會帶上對應版本這一段;發新版前先在最上面加一段 `## <版本>`。

## 0.12.0

- 用 HTTPS 連線的電腦，也能在 app 上看到 Codex 的方案用量。

## 0.11.0

- 可以從 app 傳送一則測試通知，確認這台電腦的推播設定正常。
- 在 app 打開聊天時只先讀最後一小段，網路慢時也能比較快看到對話。

## 0.10.1

- 修正 Windows 上用 `purrdr` 執行的指令失敗時，仍被當成成功的問題。
- 裝置管理的提示訊息改成較短的 `purrdr` 指令。

## 0.10.0

- 新增短指令 `purrdr`:重開終端機後打 `purrdr pair` 就能顯示配對 QR code,`purrdr help` 列出所有指令。原本的 `purrdr-host-service` 照樣能用。
- 自動更新到這版的電腦，在服務重新啟動後也會有 `purrdr`。

## 0.9.0

- 安裝時在 herdr 加上快捷鍵:在 herdr 裡按 `prefix+alt+p` 就會跳出配對 QR code。這個按鍵已經被你使用時不會加。

## 0.8.0

- 從 app 上傳的檔案改放在系統的暫存資料夾。
- 主機服務的紀錄檔集中放在一個資料夾，方便查問題。

## 0.7.0

- 在 app 上可以看到 Agent 目前的畫面。
- 送出訊息前會先確認畫面沒有變動，避免送錯地方。
- Agent 卡住或在等你回覆時，會推播通知。
- 可以排一則「Agent 做完再送」的訊息。
- 可以接續之前的對話，也能查看專案的 git 變更(唯讀)。
- 修正 Windows 上背景啟動的問題。

## 0.6.1

- 可以從 app 聊天、建立工作區，以及上傳圖片與檔案。
- 可以從 app 查看與撤銷已配對的裝置，並管理主機服務(查看狀態、立即更新、開關自動更新)。
- 有新版時會推播通知;Agent 正在工作時，自動更新會等它做完再進行。
- 補上 macOS 版的 Apple 公證。

## 0.6.0

- 可以從 app 安裝推播外掛，一台電腦能配對多台裝置。
- 安裝時會把主機服務加進 PATH,重開終端機後可以直接執行。

## 0.5.0

- 新增自動更新：每天檢查一次，有新版就自動更新;新版起不來會自動退回原本的版本。
- 新增 `update`、`version` 與 `auto-update on|off` 指令。

## 0.4.1

- 專案網址改為 `raychiutw/purrdr.host`。

## 0.4.0

- 第一個可以用一行指令安裝的版本(macOS、Linux、Windows)。
- 支援配對裝置、從 app 讀取電腦上的檔案，並可在安裝時指定 HTTPS 連接埠。

## 0.2.0

- 第一個公開版本：讓 iPhone／iPad 上的 Purrdr app 透過 HTTPS 連到電腦上的 herdr。
